# AI Motion Designer

Build an educational motion-graphics editor with Gemini and **real HyperFrames**. Plan scenes, edit their words and timing, preview a seekable animation, and render a 1280 × 720 MP4 on your computer.

Built by **LDS Team**. This is an LDS build-along companion application, version **1.0.0**. It is not a hosted video service. Start with [docs/BUILD.md](docs/BUILD.md).

## Run locally

Install Node.js 22.13+, FFmpeg (including FFprobe), and Google Chrome. Then, in this folder:

```sh
npm ci
npm run setup
npm start
```

Open **http://localhost:3082**. Use `PORT` in `.env.local` if that port is occupied. Open the address printed by this copy of the server.

Select **Explore an illustrative storyboard**. This creates a labeled, editable next-token prediction example. Or choose **Start a blank storyboard** and write your own scenes. Neither action calls an AI service.

Gemini is optional: put your key in `.env.local`, restart, write a brief, and explicitly select **Draft with Gemini**. Only that brief is sent to Google. No audio is generated by this app. Keep keys and `.data/` private.

## What you implement

- `learner/storyboard.mjs`: a bounded, grounded scene-planning contract.
- `learner/timeline.mjs`: map a playhead into the correct scene.
- `learner/composition.mjs`: escape untrusted text and derive contiguous timings.

The completed reference is in `learner/`. Starter packaging replaces these three files with `teaching/starter/`. Restore a single function with `npm run restore -- timeline`; previous work is backed up in `.backups/`.

## Verify

```sh
npm test
npm run test:export
```

The first command tests input validation, escaping, timing, provider caching/budgets, persistence and cross-origin request rejection. The export integration actually invokes HyperFrames, Chrome and FFmpeg, then checks codec, dimensions and duration using FFprobe. It performs no AI requests.

## Honest boundaries

This first version supports three predefined motion types: tokens, pipeline and compare. Gemini writes a structured plan, never executable HTML or arbitrary code. You must check facts. It does not synthesize scientific measurements, validate source claims, generate voice, host projects, render remotely, or edit imported footage.

Local exports use HyperFrames 0.8.117 with GSAP 3.14.2. HyperFrames telemetry is disabled in the renderer. Files are stored in `.data/` and survive restarts. AI attempts are limited to five per UTC day by default (failed attempts count), capped at twenty by configuration; matching validated drafts are cached. No automatic provider retries.
