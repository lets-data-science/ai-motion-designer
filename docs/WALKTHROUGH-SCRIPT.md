# Walkthrough script

The LDS guide uses an actual local-app recording with one continuous narration take. Playback timing is adjusted to follow the narration; captions and the transcript contain the same words.

AI narration uses Prateek Gaurav’s authorized voice. Voice credentials and audio source files are not included in this code repository. Building and testing the app requires no speech credits.

Current guide film: 44.88 seconds.

## Transcript

AI Motion Designer helps you turn an explanation into a moving story. Start with this illustrative storyboard, where each scene connects a clear idea to an animation. Change the title and duration, save, and watch the preview. Reloading confirms that your edit is still there. Now move a scene and check how the sequence changes. Put it back when the original order tells the story more clearly. HyperFrames renders the composition locally. We’ve shortened that wait here. Download the finished MP4, then return to your saved storyboard. Rendering itself uses no AI credits. Keep refining the sequence until the explanation is easy to follow.
